# Session 2026-10-24: M0 (Infrastructure)

## Summary
We planned and implemented milestone **M0**. The backend skeleton now runs end-to-end: `docker compose up -d` starts Postgres, Redis and nginx, the API loads settings from `.env`, Alembic applies a baseline migration, and `GET http://localhost/api/health` through nginx returns `200 {"status":"ok","postgres":true,"redis":true,"storage":true}`. The user confirmed this against real R2 credentials. The biggest change is that **file storage moved from MinIO to Cloudflare R2**. Nothing is committed yet.

## Starting point
- `backend/app/main.py` held a bare `FastAPI()`. `core/` and `services/` didn't exist.
- The venv had no DB, Redis or S3 libraries.
- `nginx/default.conf` was missing, MinIO used `:latest` tags, and the root `.env` was empty.

## Decisions made

| Topic | Decision |
|---|---|
| File storage | **Cloudflare R2** (S3 API) instead of MinIO, because the official `minio/minio` and `minio/mc` images are gone from Docker Hub and quay.io. R2 is external, so there's no storage container. |
| S3 client | `aioboto3` (async, so no blocking I/O), with `region_name="auto"` and checksums only when required (Cloudflare's recommendation). |
| Card art serving | Served from the R2 public URL (a custom domain or r2.dev), with no nginx `/media/` route. M2 adds a public-URL setting and a bucket CORS rule for presigned `PUT`s. |
| Health response | `{status, postgres, redis, storage}`. It returns 503 if any check fails. The checks run concurrently with a timeout (`HEALTH_CHECK_TIMEOUT_S`, 2 s), and failures are logged. |
| `.env` | A single file at the repo root, shared by compose and the API, and loaded by absolute path. Every setting is required, and R2 values must be non-empty, so startup fails with a clear error. |
| Host addresses | Use `127.0.0.1`, not `localhost`, in `DATABASE_URL`/`REDIS_URL`. On Windows `localhost` tries `::1` first, and the containers bind only IPv4: this cost 2 s per connection and made every health check time out. |
| Requirements | A single pinned `requirements.txt` (runtime plus dev tools), with versions taken from `pip freeze`. |

## Verification
- `pytest` (2 passed), `ruff check`, `ruff format --check` and `mypy app tests` are all clean, and `docker compose config` is valid.
- `alembic upgrade head` applies the baseline, and `alembic current` shows it as head.
- Through nginx, `/api/health` returns 200 with every check true (confirmed by the user). Stopping Redis gives 503 with `redis:false`, and it recovers once Redis is back.
- `/ws/` reaches FastAPI. `/` returns 502 until the Vite dev server exists (F0).
